# ADR-0003: 데이터 보존/삭제 옵션 및 보안(신뢰) 설계

- 상태: Accepted
- 날짜: 2025-12-27
- 맥락(Context):
  - 의사결정 단계에서 “품질 불신 + 표절/유사도 + 보안 우려”가 전환을 저해한다.
  - 생성형 기능 특성상 입력 데이터/산출물의 보존 정책이 불명확하면 신뢰를 잃는다.
- 결정(Decision):
  - 저장 모드는 2종으로 제공한다.
    - **세션 모드(기본 옵션)**: 세션 종료 후 최대 24시간 내 서버 저장 데이터 삭제(복구 불가)
    - **프로젝트 모드(옵트인)**: 기본 보존 30일, 사용자 요청 시 즉시 삭제(감사 로그 포함)
  - 감사 로그(AuditLog): 조회/생성/Export/삭제 이벤트를 기록하고 사용자에게 “누가/언제/무엇을” 수준으로 노출한다(최소).
  - 정책 명문화: 사용자 입력/산출물은 **모델 학습에 사용하지 않음**을 제품 내 정책/FAQ에 명시한다.
- 대안(Alternatives):
  - 무조건 보존: 보안 우려로 전환 저하 가능성.
  - 무조건 미보존: 편집/버전/리텐션 기능 제한, Q1 전환 저해.
- 결과(Consequences):
  - 장점: 보안 우려 완화 + 기능(편집/버전/Q1)과의 균형.
  - 단점: 삭제/감사 로그 등 운영·구현 복잡도 증가.
