## JTBD/Outcome Set (예비창업자용) — `8-2_JTBD_인터뷰_결과_보고서_작성_방법.md` 포맷 적용

### JTBD 요약 카드 1 (Core / Q2: 과제 수행자)
| 구분 | 내용 |
| --- | --- |
| **Persona / Segment** | **코어 – 예비창업패키지/대출/경진대회 등 “제출/통과”가 급한 예비창업자 (Q2)** |
| **Situation (When …)** | **마감(지원사업/대출/대회)을 7~14일 앞둔 상황** |
| **Job Statement (… I want to …)** | **나는 “사업을 제대로 모르더라도”, 심사자가 이해/납득할 수 있는 구조로 “사업계획서/재무”를 빠르게 완성해 제출하고 싶다.** |
| **Desired Outcome (… so I can …)** | **(1) 1차 제출본을 3시간 내 완성, (2) 필수 항목 누락 0건, (3) 계산 오류 0건, (4) 1회 통과(반려 0~1회)로 통과 확률을 높이기** |
| **4 Forces** | **Push:** 빈 화면·용어·재무 공포, 마감 압박  \n**Pull:** “양식 최적화 + 자동완성”으로 빠른 결과 기대  \n**Habit:** 구글 템플릿/선배 자료 복붙  \n**Anxiety:** 품질 불신·표절/유사도·보안 우려 |
| **Current Solutions / Workarounds** | 구글/네이버 템플릿, 합격자 PDF 참고, 유튜브, 소상공인/학교 교육, 고가 컨설팅(견적 단계) |
| **Switch Triggers / Barriers** | **Trigger:** 마감 임박, 제출 요구(은행/기관), 심사 기준 확인  \n**Barrier:** 가격, 보안, 산출물 품질/논리 일관성 불신 |
| **Evidence (Quotes / Data)** | “마감이 일주일 남았는데, 시장 분석/재무를 어떻게 채워야 할지 막막합니다.”(김예비)  \n“은행에서 상권분석과 추정 손익이 포함된 사업계획서를 요구합니다.”(박사장) |
| **Notes** | Q2는 “다운로드 후 해지”가 자연스러움 → 사용 중 “검증/실행관리(Q1)”로 확장되는 가교 기능 필수 |

### JTBD 요약 카드 2 (Core / Q1: 적극적 학습자)
| 구분 | 내용 |
| --- | --- |
| **Persona / Segment** | **코어 – 실패 회피/재창업/투자유치 등 “검증”이 목표인 예비·초기 창업자 (Q1)** |
| **Situation (When …)** | **개발/채용/투자유치 전, ‘지금 뛰어들면 망한다’는 두려움이 커진 상황** |
| **Job Statement (… I want to …)** | **나는 내 아이디어/가설이 맞는지, 코드를 치기 전에 시장/고객/경쟁/수익성을 데이터로 검증해 실패 확률을 낮추고 싶다.** |
| **Desired Outcome (… so I can …)** | **(1) 2주 내 핵심 가설 3개를 검증, (2) 핵심 리스크 Top3를 제거/완화, (3) 투자자/팀 설득이 가능한 근거(시장규모·단위경제) 확보** |
| **4 Forces** | **Push:** 과거 실패 트라우마(“시장 수요 없음”), 불확실성 스트레스  \n**Pull:** PMF/리스크 진단 대시보드, 코파일럿의 “반박/대안” 제시  \n**Habit:** 엑셀/폼 설문/경쟁사 수집 수작업  \n**Anxiety:** 데이터/리서치 신뢰성, 시간이 오래 걸릴까 걱정 |
| **Current Solutions / Workarounds** | 직접 경쟁사 100곳 엑셀 분석, 설문(구글폼), 유료 콘텐츠/툴 구독, 리서치 보고서 발췌 |
| **Switch Triggers / Barriers** | **Trigger:** 투자자 “시장 작다” 질문, 개발 착수 직전, 공동창업자 합류  \n**Barrier:** 데이터 출처 신뢰, 분석/해석 난이도 |
| **Evidence (Quotes / Data)** | “코드를 한 줄이라도 짜기 전에, 내 가설이 맞는지 데이터로 철저히 검증하고 PMF를 찾고 싶다.”(최민혁)  \n“VC가 신뢰할 만한 TAM-SAM-SOM 근거가 부족합니다.”(한서윤) |
| **Notes** | Q1은 리텐션/LTV 핵심. “문서 생성”이 아니라 “가설-검증-실행관리” 루프를 만들어야 함 |

| 필수 항목 누락 0건(양식 적합) | 4 | 2 | 2.4 | 0.4 | 0.8 | 지원사업/대출 양식 준수 |
| 2주 내 핵심 가설 3개 검증(고객/시장/가격) | 5 | 2 | 3.0 | 0.2 | 0.6 | Q1(검증 집착), 재창업/투자유치 |
