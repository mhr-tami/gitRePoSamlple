# EasyPlan.AI (초보 창업가 대상 SaaS형 온라인 비즈니스 컨설팅) v0.1
- Owner 팀: Product Team A
- 최종 업데이트: 2025-12-27

## 1. 개요·목표
- **문제 정의(Pain 지표 포함)**: 
    - **높은 이탈률**: 예비 창업가의 60%가 전문 용어(TAM/SAM/SOM, PMF 등)와 재무 계획의 어려움으로 인해 사업계획서 작성을 중도 포기함 (탐색/사용 단계 이탈).
    - **낮은 완성도**: 초보자가 작성한 계획서의 80%가 재무제표 계산 오류 또는 논리적 불일치(Front-back inconsistency)를 포함.
    - **심리적 장벽**: "빈 화면 공포" 및 "실패에 대한 두려움"으로 인해 작성 시작까지 평균 7일 소요.
- **목표(Desired Outcome 수치화)**: 
    - **작성 시간 단축**: 기존 3일(72시간) 소요되던 초안 작성을 **3시간 이내**로 단축.
    - **심리적 장벽 해소**: 사용자 AOS(사용성) 점수 **4.0/5.0 이상** 달성 (매우 쉬움).
    - **결과물 품질**: 자동 생성된 재무제표의 **계산 오류 0건**, 논리적 정합성 오류 0건.
- **성공 지표(북극성/보조 KPI)**:
    - **북극성 KPI (North Star Metric)**: **유료 고객의 사업계획서 작성 완료율 (목표: 85% 이상)**.
    - **보조 KPI**: 
        - 정부지원사업 서류 합격률 (목표: 30% 이상, 업계 평균 대비 2배).
        - 재무 섹션 작성 이탈률 (목표: 10% 미만).
        - NPS (Net Promoter Score): 50점 이상.

## 2. 사용자와 페르소나
- **핵심 페르소나**: "불안한 초보 창업가" (Segment Q2 & Inno-User)
    - **페르소나 A (박은숙, 50대)**: 경력 단절 후 창업. "컴맹이라 엑셀이 무섭고, 전문 용어는 외계어 같다."
    - **페르소나 B (오다빈, 20대)**: 아이디어만 많은 대학생. "뭐부터 써야 할지 막막하고 빈 화면이 두렵다."
- **핵심 Needs**: 
    - **Easy Mode**: 어려운 경영학 용어 대신 생활 언어 사용 ("TAM" -> "우리가 만날 수 있는 전체 손님 수").
    - **Auto-Financials**: 복잡한 수식 없이 Q&A로 끝나는 재무제표.
    - **Validation**: 내 사업이 망하지 않을 것이라는 데이터 기반 확신.

## 3. 사용자 스토리와 수용 기준 (AC, Acceptance Criteria)
### Story 1. Easy Mode (용어 번역 및 가이드)
**Story**: As a **경영 지식이 없는 초보 창업가**, I want **복잡한 용어가 쉬운 생활 언어로 번역되어 가이드되길**, so that **두려움 없이 문서를 계속 작성할 수 있다.**

**Acceptance Criteria (AC)**:
1. **Given** 사용자가 '시장 규모 추정(TAM/SAM/SOM)' 입력 단계에 진입했을 때, **When** 별도의 조작 없이도, **Then** 해당 용어의 뜻이 "전체 시장 / 유효 시장 / 수익 시장"과 같은 직관적인 설명으로 툴팁 또는 사이드바에 표시되어야 한다.
2. **Given** 사용자가 전문 용어(예: BEP)를 입력창에 마우스 오버했을 때, **When** 0.5초 이상 머무르면, **Then** "손익분기점: 돈을 벌기 시작하는 시점"이라는 설명 팝업이 노출되어야 한다.
3. **Given** 사용자가 가이드를 읽고 내용을 입력할 때, **When** 추천 예시 버튼을 클릭하면, **Then** 동종 업계의 모범 답안 예시가 3개 이상 제시되어야 한다.

### Story 2. Auto-Financials (Q&A 기반 재무제표 생성)
**Story**: As a **엑셀에 익숙하지 않은 창업가**, I want **질문에 답하는 것만으로 손익계산서가 만들어지길**, so that **계산 오류 없는 재무 계획을 제출할 수 있다.**

**Acceptance Criteria (AC)**:
1. **Given** 재무 계획 단계에서, **When** 사용자가 "제품 가격(P)"과 "예상 판매량(Q)", "고정비(임대료 등)"를 입력하면, **Then** 시스템은 즉시(1초 이내) 3개년 추정 손익계산서와 매출액을 계산하여 표 형태로 미리보기를 제공해야 한다.
2. **Given** 사용자가 입력 값을 수정(예: 가격 인상)했을 때, **When** 엔터키를 누르거나 포커스를 이동하면, **Then** 연동된 모든 재무 수치(영업이익, 순이익 등)가 자동으로 재계산되어야 하며 오류(Error)가 발생하지 않아야 한다.
3. **Given** 필수 입력 값(예: 원가)이 누락되었을 때, **When** '다음 단계'로 이동을 시도하면, **Then** 이동을 차단하고 "원가를 입력해주세요"라는 명확한 에러 메시지와 해당 필드로 포커스를 이동시켜야 한다.

### Story 3. AI Logic Check (사업 타당성 진단)
**Story**: As a **확신이 부족한 창업가**, I want **내 사업 계획의 논리적 허점을 AI가 진단해주길**, so that **심사위원의 압박 질문에 미리 대비하고 합격률을 높일 수 있다.**

**Acceptance Criteria (AC)**:
1. **Given** 모든 항목의 작성이 완료되었을 때, **When** 'AI 진단하기' 버튼을 클릭하면, **Then** 1분 이내에 논리적 모순(예: "타겟 고객은 20대인데 마케팅 채널은 신문 광고임")을 최소 1건 이상 찾아내어 리포트로 제공해야 한다.
2. **Given** 진단 결과 리포트에서, **When** 발견된 문제점을 클릭하면, **Then** 해당 내용을 수정할 수 있는 입력 섹션으로 즉시 이동(Deep Link)해야 한다.
3. **Given** 진단 점수가 60점 미만일 때, **When** 결과 화면이 로드되면, **Then** "제출 위험" 경고 뱃지와 함께 구체적인 개선 가이드(Action Item)를 3가지 이상 제시해야 한다.

## 4. 기능 요구사항 (Functional)
- **Must Have (필수)**:
    - **Easy Mode 에디터**: 섹션별 가이드, 용어 툴팁, 자동 저장.
    - **Q&A 재무 계산기**: 입력 변수(P, Q, C) 기반 3개년 재무제표(손익, 현금흐름) 자동 생성 로직.
    - **정부지원사업 표준 양식 변환**: 작성된 데이터를 HWP/PDF 표준 양식(PSST 방식)으로 렌더링 및 다운로드.
    - **회원 관리**: 소셜 로그인, 프로젝트 저장/불러오기.
- **Should Have (권장)**:
    - **AI 사업타당성 진단 리포트**: LLM 기반 논리적 정합성 체크 및 점수화.
    - **업종별 템플릿**: 요식업, 플랫폼, 제조 등 업종별 예시 데이터셋.
- **Could Have (가능)**:
    - **경쟁사 분석 자동화**: 키워드 입력 시 크롤링 기반 경쟁사 리스트업.
    - **실시간 협업**: 팀원 초대 및 동시 편집.
- **Won't Have (제외)**:
    - **전문가 1:1 매칭 (추후 도입)**.
    - **모바일 앱 (작성 편의성 고려 PC Web 우선)**.

## 5. 비기능 요구사항 (NFR, Non-Functional Requirement)
- **성능 (Performance)**:
    - 단순 페이지 로딩 및 저장: **p95 응답 시간 ≤ 500ms**.
    - AI 진단 및 생성 요청: **p95 응답 시간 ≤ 10초** (사용자에게 진행률 표시 필수).
    - 재무 계산: 클라이언트 사이드 즉시 반응 (**≤ 100ms**).
- **신뢰성 (Reliability)**:
    - 월 가용성 **≥ 99.9%** (정부지원사업 마감 시즌 트래픽 폭주 대비).
    - 데이터 손실률 **0%** (작성 중 비정상 종료 시 로컬 스토리지 및 서버 1분 단위 자동 저장).
- **보안 (Security)**:
    - 사용자 사업 아이디어 보호를 위한 **DB 암호화 (AES-256)** 적용.
    - 모든 데이터 전송 구간 **SSL/TLS 암호화**.
    - 개인정보보호법 준수 (회원 탈퇴 시 데이터 파기 절차 자동화).
- **모니터링 (Monitoring)**:
    - 주요 API 에러율 1% 초과 시 슬랙 알림.
    - AI 토큰 사용량 및 비용 실시간 대시보드 모니터링.

## 6. 데이터·인터페이스 개요
- **핵심 엔터티**:
    - `Project`: 사용자별 사업계획서 (필드: Title, Step_Status, Final_Score).
    - `Section_Data`: 각 단계별 입력 데이터 (JSON 형태, 예: {"problem": "...", "solution": "..."}).
    - `Financial_Model`: 재무 가정 및 결과값 (필드: Price, Quantity, Cost_Fixed, Cost_Variable).
- **인터페이스 개요**:
    - **Wizard UI**: Step-by-Step 진행 방식 (1단계: 아이디어 -> 2단계: 시장 -> ... -> 5단계: 재무).
    - **Split View**: 좌측(가이드/예시) - 우측(입력창) 구조로 "보고 따라쓰기" 최적화.
    - **Dashboard**: 내 프로젝트 진행률 및 AI 진단 점수 시각화.
- **API**:
    - `POST /api/v1/projects/{id}/analyze`: AI 진단 요청 (Input: Project Data, Output: Score & Feedback).
    - `POST /api/v1/projects/{id}/export`: 문서 변환 요청 (Output: Download URL).

## 7. 범위(In/Out), 리스크·가정·의존성
- **In-Scope**: 웹 기반 사업계획서 작성 도구, AI 진단, HWP 다운로드.
- **Out-Scope**: 모바일 앱, 오프라인 컨설팅 매칭, 투자자 매칭 플랫폼 기능.
- **리스크 및 대응(Risk Mitigation)**:
    - **Risk 1**: AI의 할루시네이션으로 인한 잘못된 재무 조언. 
        - **대응**: 재무 계산은 AI가 아닌 **Rule-based 엔진**으로 처리하고, AI는 문장 다듬기 및 논리 체크에만 활용.
    - **Risk 2**: 정부지원사업 양식 변경.
        - **대응**: 양식 렌더링 엔진을 모듈화하여 양식 변경 시 템플릿만 교체 가능하도록 설계 (ADR-002).
    - **Risk 3**: 고비용 LLM API 호출로 인한 수익성 저하.
        - **대응**: 단순 요약/번역은 경량 모델(Gemini Flash/GPT-4o-mini) 사용, 심층 진단만 고성능 모델 사용.
- **가정 및 의존성**:
    - 사용자는 Chrome, Edge 등 최신 데스크탑 브라우저를 사용한다고 가정함.
    - OpenAI 또는 Google Gemini API의 가용성에 의존함.

## 8. 실험·롤아웃·측정
- **베타 테스트**:
    - 대상: 초기 창업가 커뮤니티 모집단 50명 (Q2 세그먼트 우선).
    - 실험: "Easy Mode" 적용 그룹 vs "기존 템플릿" 제공 그룹의 **완성률 및 소요 시간 비교**.
- **롤아웃 계획**:
    - v0.1: 사내 테스트 및 Alpha (기능 검증).
    - v0.5: Closed Beta (초대 기반).
    - v1.0: Open Beta (정부지원사업 시즌 1개월 전 런칭).
- **성공 기준 검증**:
    - 로그 데이터 기반: 세션 당 평균 체류 시간, 단계별 이탈률(Funnel Analysis).
    - 사용자 피드백: 작성 완료 후 팝업 설문 (NPS, "친구에게 추천하겠습니까?").

## 9. 근거 (Proof)
- **시장 데이터**: 초기 창업가의 60%가 SAM 내 'Q1(적극 학습)' 및 'Q2(과제 수행)' 그룹에 속함 (시장 분석 리포트 참조).
- **AOS 데이터**: '쉬운 사용성'에 대한 니즈 점수 4.0 확인 (Gemini-ValueProPositionSheet 분석 결과).
- **경쟁 우위**:
    - 기존 컨설팅 대비 비용 **1/10** (50만원 -> 월 5만원).
    - 기존 엑셀 작업 대비 시간 **1/24** (72시간 -> 3시간).
